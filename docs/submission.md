# Submission checklist

- Review and understand every source file and the tests.
- Verify the README's startup commands from a clean clone.
- Submit a public GitHub or GitLab repository with the existing commit history.
- Record an English code walkthrough, at most 15 minutes, screen sharing with
  the camera on. Upload to Loom or unlisted YouTube.
- Record the actual total time you spent, including review and recording.
  Automated build duration does not establish the candidate's working hours.
- Reply to the original task email with both links and the actual hours.

Suggested email:

```text
Hi,

Here is my caching service submission:

Repository: [public repository URL]
Video walkthrough: [Loom or unlisted YouTube URL]

I spent [actual number] hours on the task.

Best regards,
[your name]
```
